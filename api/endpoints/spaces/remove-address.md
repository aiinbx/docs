# Remove an address from its space

[View on docs.aiinbx.com](https://docs.aiinbx.com/api/endpoints/spaces/remove-address)

Removes the assignment: from its next email on, the address is where its untagged address is assigned — `anna@agents.com` for `anna+orders@agents.com` — else in its domain's space again. Mail it already has stays in the space it was in. An address that is not assigned is `404 not_found`.

`DELETE /addresses/{address}`
